## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

**How does a Windows-style file path differ from a Linux-style file path?**

**One command from this week you feel most confident with, and why:** 1. Difference between a file and a folder, and how they form a tree:  A folder is like storage that keeps things organized together, and a file is the actual item inside it — like a PDF, a PNG, or an image. The folder houses the files. They form a tree because folders can hold other folders, which branch out into more folders and files. For example, I might have a "2025 Taxes" folder. Inside it, a folder for clients. Inside the clients folder, a separate folder for each client's name, and inside each client's folder, their actual documents. So it branches out like a tree — folders are the branches, and the files are the leaves at the end.  2. Windows-style vs. Linux-style file path:  A Windows-style path uses backslashes () and starts with a drive letter, like C:\Users\Morgan\file.txt. A Linux-style path uses forward slashes (/) and starts from the root with no drive letter, like /home/morgan/file.txt. So the two biggest differences are the slash direction and the drive letter, which Windows has and Linux doesn't. Linux feels easier to me because the forward slashes and simple /home layout are cleaner than Windows drive letters.  3. Command I feel most confident with:  The command I feel most confident with is pwd, because after a lot of practice it's the one I reach for to find my location. Whenever I got lost in a folder tree this week, pwd told me exactly where I was so I could recover. I'm also comfortable with ls to see what's in a folder and cat to read a text file, but pwd is the one I trust most because it always tells me where I am.
