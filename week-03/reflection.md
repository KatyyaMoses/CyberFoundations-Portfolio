## Prompts

1. What clicked for you this week?

What clicked for me this week was actually understanding the command line once I started playing with it. Being able to use different commands to explore folders and read files was the biggest click for me. Knowing the commands, what they do, and what they stand for made it all start to make sense.

2. What's still confusing?

I think I mostly worked it out, but one thing that took a minute was remembering that after I run a command, I have to use ls to see what's there. That habit took some getting used to. The other thing that's still a little confusing is moving an item into a certain location — that one trips me up sometimes. But I'm pretty sure that with more practice it'll get easier.

3. How does this week's material connect to a cybersecurity career?

These feel like foundational skills. I might rarely touch the command line depending on where I end up, but since I don't fully know yet where I want to go in cybersecurity, I think these basics are important no matter what. Having a solid foundation in how files, folders, and commands work will help me in whatever direction I choose.

4. One thing you'd tell a friend just starting this course:

I'd tell them to dedicate some time to learn the material. We find time for everything we want to do in life — we find time to watch TV, time to go out to eat — but those things rarely change our lives. So make time for this, even if you have to put it on a schedule. Understand that learning this material can change the trajectory of your future.
